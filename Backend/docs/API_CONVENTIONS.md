# API Conventions

The agreed rules for how Flutter and the backend talk to each other.
Endpoint details and examples: [API Contract.md](API%20Contract.md).

> Any change to these rules or to an endpoint must be told to the Flutter team (Dana) **before** merging, and written on the related Trello card.

---

## 1. Basics

- REST over HTTPS, JSON (`application/json`, UTF-8). No GraphQL, no gRPC.
- Base path: `/api`.
- No API versioning in the MVP (backend and app ship together). Add it only if Triply gets a public API.

## 2. Naming

| Rule | Example |
|---|---|
| Plural nouns for collections | `GET /api/trips` |
| One item by id | `GET /api/trips/{id}` |
| Child resource under its parent | `GET /api/trips/{id}/itinerary` |
| Actions that are not plain CRUD use a verb under the resource | `POST /api/trips/{id}/generate`, `/save`, `/archive`, `/restore` |
| No verbs in names | ❌ `/api/getTrips` |

## 3. Methods and success codes

| Method | Use | Success |
|---|---|---|
| GET | Read | `200` |
| POST | Create, or run an action | `201` (create) / `200` (action) |
| PATCH | Partial update | `200` |
| PUT | Replace a whole set (trip details, user preferences) | `200` |
| POST `/auth/logout` | Revoke a refresh token | `204` |

## 4. JSON

- Field names: `camelCase`.
- Never return database entities; every endpoint has its own request and response DTO.
- Dates: `yyyy-MM-dd` (`2026-11-01`). Timestamps: UTC ISO-8601 (`2026-09-24T10:15:52Z`).
- Money: a decimal `amount` with a currency code or currency id. Costs generated by the system are marked `isEstimated: true`.
- IDs: users, trips, itineraries, days, items and AI generations use GUID strings. Destinations, places, currencies and categories use numbers.

## 5. Errors

Errors use the ASP.NET Core `ProblemDetails` shape.

**400 — validation**
```json
{
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": { "travelerCount": ["TravelerCount must be greater than 0."] }
}
```
**401 — login failed** (same message for wrong password and unknown email)
```json
{ "title": "Invalid email or password.", "status": 401 }
```
**500 — unexpected** (never contains a stack trace)
```json
{ "title": "An unexpected error occurred.", "status": 500 }
```

| Code | Used for |
|---|---|
| `400` | Bad input |
| `401` | Missing, invalid, or expired token / bad credentials |
| `404` | Not found, **or not owned by you** (we don't reveal that another user's trip exists) |
| `409` | Old `expectedVersion`, or action not allowed in the current status |
| `422` | AI plan failed validation |
| `429` | Rate limit exceeded |
| `502` | Gemini failed |

**Flutter rule:** decide by the HTTP **status code**. The `title` text may change.

Note: some AI, itinerary and trip conflict responses use `{ "message": "..." }` (and `errors`) instead of `title`. Read `message` when `title` is missing.

## 6. Authentication

```http
Authorization: Bearer <token>
```
- Public: register, login, refresh, email confirm/resend, forgot/reset password, `/destinations/assets`, `/health`.
- Everything else needs a token.
- Access token **15 minutes**, refresh token **30 days** (rotated on each refresh). Issuer `Triply`, audience `TriplyClients`.

## 7. Versioning trips (`version`)

Every trip has an integer `version`. Send it back as `expectedVersion` when you edit or regenerate part of a trip. If it is old, the API returns `409` and changes nothing. Reload the trip and try again. Successful `generate` responses return the new `tripVersion`.

## 8. Rate limits

| Scope | Limit |
|---|---|
| Login | 5 / minute |
| General endpoints | 10 / minute |
| AI generation | 10 / hour |

Per logged-in user, or per IP for anonymous calls. Over the limit → `429`.

## 9. Pagination

Not used in the MVP (small data). If added later:
`GET /api/trips?page=1&pageSize=20` → `{ "items": [], "page": 1, "pageSize": 20, "total": 42 }`.

## 10. Swagger

Swagger is generated from the controllers and is the most accurate reference for the current code.
- UI: `http://localhost:8080/swagger` (Development only, not on Render)
- JSON: `http://localhost:8080/swagger/v1/swagger.json`

`docs/openapi.yaml` is an old hand-written draft. To refresh it, run the API locally, then:
```powershell
curl http://localhost:8080/swagger/v1/swagger.json -o docs/openapi.yaml
```
